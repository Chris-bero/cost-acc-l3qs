Manufacturing vs Non-Manufacturing Costs

Manufacturing (Product): DM + DL + MOH (Direct & Indirect). Inventoriable costs.
Non-Manufacturing (Period): Selling + Administrative expenses. Expensed immediately.

Cost Behavior Classifications

Variable Cost: Total changes with activity; per unit constant (e.g., DM, DL)
Fixed Cost: Total constant within relevant range; per unit decreases as activity increases (e.g., Rent)
Mixed Cost: Contains both fixed and variable elements (Y = a + bX)

High-Low Method Formulas

b = (High Cost - Low Cost) / (High Activity - Low Activity)
a = High Cost - (b × High Activity)
Y = a + bX

MOH Classification Note

MOH can be Fixed OR Variable depending on nature:

  • Fixed MOH: Factory Rent, Supervisor Salary, Depreciation
  • Variable MOH: Indirect Materials, Indirect Labor, Electricity
